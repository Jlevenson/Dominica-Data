# Analysis code

Python 3 with pandas, numpy and statsmodels.

To rerun, copy `../species_by_year.csv` to `reef_dominica_species_year_long.csv` and `../effort_by_year_detail.csv` to `effort_by_year.csv` in a working folder, then run `analyze.py` followed by `export.py`. `export.py` writes the `out_*` files that become `effort.csv`, `lionfish.csv`, `trends.json`, `periods.json` and `groups.json`.
